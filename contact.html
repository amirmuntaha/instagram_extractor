Contact Us

We would love to hear from you

Get in touch

This is a free, open-source project. The best way to reach us is through our public GitHub repository, where you can open a new issue to send feedback, report a bug, or ask a question. Every issue is read and replied to in the open.

You can also browse existing discussions and reports on the GitHub issues page, or view the full source code in the project repository. Using GitHub keeps communication transparent and searchable, so answers to common questions stay available for everyone.

You do not need a paid account to contact us: creating a free GitHub account takes a minute and lets you open and follow issues.

What to contact us about

  • Bug reports. If a post will not load, the QR code looks wrong, or the poster download fails, open an issue and include the Instagram URL you tried and the browser you are using so we can reproduce the problem.
  • Feedback and ideas. Have a suggestion for a new feature or an improvement to the layout? Open an issue and describe it. We read every report and use it to guide what we build next.
  • Privacy requests. For anything relating to your privacy or the handling of data, open an issue on the repository and see our Privacy Policy for full details on how the site works.

Please note that we are not affiliated with Instagram or Meta and cannot help with account issues, password resets, or content disputes on Instagram itself.
